# Category and dropdown artwork

21 vector illustrations (`<page>-<n>.svg`, 16:10) used by the category pages and the nav dropdowns.
SVG is resolution-independent, so it is pixel-sharp on any screen, including 8K.
8K PNG masters (7680x4800) are in the separate `8k-masters` folder delivered with the project.
To change one, edit/replace the SVG with the same file name.
