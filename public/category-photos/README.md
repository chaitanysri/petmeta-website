# Real photos (optional)

Drop a photo here named exactly like the slot, e.g. `food-0.webp`, and it replaces the illustration automatically
on the category page and in the nav dropdown. Missing files fall back to `/category-images/<name>.svg`.
Format: WebP, 16:10, about 2400 px wide (keep your 8K master elsewhere). Slots: food, accessories, grooming, vet, toys, health, offers, each -0, -1, -2.
